# Knowledge Room

Knowledge Room è una web application che trasforma un argomento in un grafo esplorabile di entità e connessioni. I dati sono ricavati da Wikidata e Wikipedia, con schede informative e preferiti salvati localmente.

## Funzionalità

- Ricerca di argomenti ed entità
- Esplorazione interattiva di grafi semantici
- Schede informative basate su Wikipedia e Wikidata
- Salvataggio locale di grafi e contenuti preferiti

## Stack tecnologico

React · Vite · React Router · Force Graph · Framer Motion · Wikidata · Wikipedia

## Avvio rapido

**Prerequisiti:** Node.js 18 o successivo.

```bash
npm install
npm run dev
```

L'applicazione sarà disponibile all'indirizzo indicato da Vite.

## Script

| Comando | Descrizione |
| --- | --- |
| `npm run dev` | Avvia l'ambiente di sviluppo |
| `npm run build` | Genera la build di produzione |
| `npm run preview` | Visualizza localmente la build |
| `npm run lint` | Esegue i controlli ESLint |

## Dati e attribuzioni

Il progetto utilizza le API pubbliche di [Wikidata](https://www.wikidata.org/) e [Wikipedia](https://www.wikipedia.org/). I contenuti restano soggetti alle rispettive licenze e condizioni d'uso.
